# Real locked CLI bundle evidence

The local prototype installed the real required Prisma AIRS CLI **5.2.0** and SDK
**0.28.0** by ordinary scoped package name on npm **10.9.8** and **12.0.2**.
Both fresh Linux musl installations ran the immutable source-154 harness binary,
managed CLI diagnostics, 20 capability command contracts, and actual
PDF/PNG/JPEG/SVG/DOCX corpus generation. Each made four authenticated requests to
the isolated synthetic private registry and zero public registry requests.

This is local feasibility evidence. It does not establish GitHub Packages
publication, teammate authorization, macOS/Windows execution, or production
authentication readiness. No real registry credentials were used.

- [Prototype summary](prototype-summary.json) records exact hashes, versions,
  timings, payloads, first-attempt corrections, and limitations.
- [Evidence index](EVIDENCE-INDEX.json) binds every retained original source,
  lockfile, receipt, package-file listing, and independent review by SHA-256.
- [Compressed original evidence](prototype-evidence.tar.gz) preserves those
  bytes with deterministic archive metadata. These are historical experiment
  sources, not installation instructions. No native executables, package archive
  payloads, real credentials, or private runtime logs are included.
- [Maintained source checks](maintained-unit-checks.json) records the later
  implementation at `8f7de9f75` and archive stage `eff054c80`. These unit results
  are distinct from prototype install measurements.

The prototype launcher tarball remains at
`/var/tmp/airs-real-cli-bundle-prototype/packed/cdot65-prisma-airs-harness-0.1.0-alpha.9.tgz`:
43,089,708 bytes, SHA-256
`163222209bc2f89f1babd6ec9d1e04bae58751b629937fc08a1796e9e9b84283`.
All 73 selected package versions and 69 recognized license files were checked.
The seven image payload packages cover Linux x64 with both libcs, Apple Silicon,
and Windows x64. Non-Linux payloads were inspected, not executed. No Intel Mac
payload was downloaded or included. The separate Linux harness native archive
is 150,127,860 bytes; it is not included in the 43 MB launcher figure.

The maintained packager adds opt-in `--bundle-cli` to `--scoped`, preserves
literal dependency pins and private candidate markers, derives image payloads
from every supplied supported native target, and records the source lock and
tooling digests. It verifies actual names/versions, archive SHA-512, complete file
inventory, and license hashes. Adversarial tests cover unexpected Intel payloads,
changed/missing files, path aliases, links, devices, Windows reparse points,
resource limits, required peers, and unexpected registry locations.

Installed Windows command shims deliberately fail with an explicit unsupported
validation error in this private stage. Their canonical generated bytes still
need verification. POSIX generated command links must resolve to the exact
declared, hashed package target. Real maintained-package install receipts and
desktop acceptance must be added separately before any promotion.
